## Trainer notes — what is deliberately in this file

Do not read this to the room. Use it to steer.

- **The planted unresolved item** is the February insurance information that was promised and never
  sent. Exercise 2 Prompt 1 asks for anything unresolved from prior interactions — this is it, and
  it is the moment an adviser audience sits up, because everyone recognises it.
- **The three-line file note** is the argument for the whole PUC. Ask the room how typical it is.
- **The pattern across interactions** is the real content: three separate contacts, each handled
  correctly in isolation, that together describe a member approaching retirement with active
  questions and no coordinated response. No single person did anything wrong. That is what makes it
  a systems point rather than a performance one — keep it framed that way.
- **The advice trap.** This file is deliberately constructed so that Exercise 5's first prompt
  ("what should they do?") will produce something that reads like personal advice — default option
  for 17 years, approaching retirement, unused contribution capacity. That output is the teaching
  moment. Let it happen, then dismantle it.
- **What is genuinely absent:** his actual retirement timing, his objectives, his risk tolerance,
  the household's full position, any other assets, and his partner's circumstances. None of that is
  in the file. Any recommendation built on this data would be built on air — which is precisely the
  point to make when the room is impressed by the Exercise 5 Prompt 1 output.
